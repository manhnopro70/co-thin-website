📖 Hướng dẫn cập nhật website

  1. Nhấn nút "📋 Sao chép nội dung" bên dưới
  2. Mở GitHub → vào repo co-thin-website
  3. Nhấn vào file data.json → nhấn biểu tượng ✏️ Edit
  4. Xoá toàn bộ nội dung cũ → Dán (Ctrl+V) nội dung mới vào
  5. Nhấn "Commit changes" → chờ 1–2 phút là website tự cập nhật!
